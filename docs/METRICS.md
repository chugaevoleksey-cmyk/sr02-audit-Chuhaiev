# Відтворення метрик

dotnet run --project tools/Metrics -c Release -- src

Метрики production-коду лише src/*.cs. Повна CSV охоплює всі методи й конструктори (до 26, після 36); в основній таблиці — 15 найгірших методів із тілом понад 5 логічних рядків. Середня CC рахується для всіх 26/36. LOC — кількість фізичних рядків, у яких є токен тіла, крім самих дужок; коментарі та порожні рядки виключені. Один рядок з кількома операторами рахується одним, як у методичці. Фізичний обсяг кінцевої версії без TODO виміряно на after-refactoring. TODO після цього тегу не змінюють LOC токенів, CC чи CSV.

CC=1+if+цикли+case+catch+?:+&&+||+??+?. (кожне входження). Else, try та finally самі не додають. Вкладеність: тіло 1, вкладений керувальний вузол +1, else-if має вкладений вузол if. Fan-out — різні власні типи за семантичною моделлю Roslyn, включно з enum, без самого типу й BCL. Автоматичні посилання розпізнаються за символами, а не пошуком підрядка.

Клон — однакова послідовність токенів 6 логічних рядків у різних місцях; коментарі та пробіли ігноруються, назви й літерали збережені. До: 5 перекривних шестирядкових вікон, що утворюють 2 родини (залишок і рядок звіту). Після: 0 вікон, 0 родин. Це не обіцянка відсутності семантичного дублювання довільної форми.

Ручна перевірка: Dispense=1+13 if+2 foreach+2 &&+1 ||+2 case=21; Receive=1+7 if+1 foreach+2 ||=11; BatchesFor=1+1 if+1 foreach+1 while+1 &&=5. Інструмент повернув 21,11,5.
